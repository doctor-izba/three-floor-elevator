# Connected elevator HMI
Run START_DEMO.cmd in the package root and follow START_HERE.md.
Node.js 22+ and npm are required; the first run installs pinned dependencies.
Dashboard: http://127.0.0.1:1888/dashboard/elevator
Editor: http://127.0.0.1:1888/
Local MQTT: 127.0.0.1:1889
Open TriLOGI_Projects/05_Connected_Elevator_MQTT.PC7 in i-TRiLOGI 7.5+, press Ctrl+F9, wait for TRILOGI CONNECTED, then Reset and Start.
The native ladder controls the system. Node-RED simulates field mechanics only.
Detailed Russian demo: Defence_Guide_RU.md in the package root.
